# WeGolden Sales Hub (internal draft)

Internal static site for WG sales staff in MENA and Iran. Not a final policy document and not published from this package until the Regional Head approves.

## Languages

- English (default): pages in this folder
- فارسی: `fa/`
- العربية: `ar/`
- کوردی (Sorani): `ckb/`

Translated pages are machine-translation drafts for native-speaker review. If there is any difference, the English version prevails.

## GitHub Pages

Asset and page links are **relative**, so the site works at the repository root or under a project site such as `https://<org>.github.io/wg-sales-hub/`.

Suggested publish steps (do not run until approved):

1. Copy the contents of this folder (including `.nojekyll`) to the `wg-sales-hub` repository.
2. Enable GitHub Pages from the repository root (or `/docs` if you place the files there).
3. Confirm the language switcher and CSS still load on `/` and on `/fa/`, `/ar/`, `/ckb/`.

This package does not include a deploy step.
